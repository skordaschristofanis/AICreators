## Contributing
All contributions to the AICreators project are welcome! Here are some ways you can help:
- Report a bug by opening a [GitHub](https://github.com/skordaschristofanis/AICreators/issues) or a [GitLab](https://gitlab.com/christofanis.skordas/aicreators/-/boards) issue.
- Add new features, fix bugs or improve documentation by submitting a [GitHub](https://github.com/skordaschristofanis/AICreators/pulls) or a [GitLab](https://gitlab.com/christofanis.skordas/aicreators/-/merge_requests) pull request.

Please adhere to the [GitHub flow](https://docs.github.com/en/get-started/quickstart/github-flow) model when making your contributions! This means creating a new branch for each feature of bug fix, and submitting your changes as a pull request against the main branch. If you're not sure how to contribute, please open an issue and we'll be happy to help you out.

By contributing to the AICreators project, you agree that your contributions will be licensed under the MIT License.
